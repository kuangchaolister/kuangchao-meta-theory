# 狂潮元理论 kuangchao-meta-theory
> A meta-theory for Transformer LLM

## 📄 简介
本项目为独立研究者「狂潮」提出的大模型表征动力学元理论，包含本体公理体系、动态算子定义、数学机理附录、勘误增补页，面向 Transformer 自注意力内在行为、幻觉、静默覆盖、同源自噬等现象做统一归因。

## 📦 文件清单
- `狂潮元理论V2.4最终版`：理论本体，封档版
- `V2.4‑errata01`：勘误 & 增补注释页
- `数学机理附录 v1.2`：形式化数学推导、引理与证明
- 配套 PDF：用于 Zenodo 归档、引用分发

## 📌 版本规则
- 日常提交：迭代草稿，不生成 DOI
- Release 版本：封档定稿，触发 Zenodo 自动归档，分配独立永久 DOI
- 当前正式封档版本：`v2.4`
