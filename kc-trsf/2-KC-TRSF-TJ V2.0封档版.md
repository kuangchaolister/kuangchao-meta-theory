# KC‑TRSF‑TJ 狂潮‑动态推荐变体 V2.0（完整待审查封档版）

> 
> 定位：基于实时状态流与动态叠权的下一代意图推荐引擎
> 目标：彻底废除基于历史标签的静态拟合（马后炮范式），实现「实时行为感知 → 多维因子提取 → 惯性 / 异源双轨叠权 → 意图预判推荐」端到端闭环。
> 配套说明：与 KC‑TRSF‑SS（意图搜索变体）成对；原生支持接收 SS 输出的`intent_contract`意图契约，为预印本第三篇《双流合一》提供原生架构支撑；新增**新用户冷启动策略、历史惯性权重池老化遗忘策略、商业分发联动契约预埋**。
> 重要声明：本文为范式级架构设计；训练超参、具体阈值、部署优化属于后置工程，不在本范式定义范围。

## 一、全局双流模型拆解

### 1. 权限‑状态流（系统里有什么，如何演变）

- 输入域：
1）用户端上报：点击序列、停留时长、滑动速度、设备环境、会话上下文；
2）**可选外部输入：external_intent_contract，来自 KC‑TRSF‑SS 搜索变体输出的标准意图契约（搜索完成后直接注入推荐链路）。**
- 核心状态库
  - **动态行为队列 Action Queue**：滑动窗口大小的实时动作序列，携带高精度时间戳，只保留近期有效行为。
  - **立体意图结构 3D Intent Structure**：多路因子头生成的当下用户状态表征，替代传统静态用户标签。若传入`external_intent_contract`，会与行为推导因子做加权融合。
  - **历史惯性权重池**：持久记录用户各意图维度上累积的置信度，代表用户长期偏好基线；内置老化遗忘机制。
  - **异源阈值库**：保存各维度触发突变的临界判定条件，用于识别行为脱离历史轨道。
- 输出域：排序信息流列表、可审计的触发理由、内部状态 Debug 字段。

### 2. 边界‑执行流（谁在什么条件下执行）

- 意图演化引擎：处理行为序列时序衰减，对比当前与历史意图表征，输出同源 / 漂移 / 异源状态信号；执行历史惯性权重池老化遗忘。
- 双轨叠权闸门：执行**确定性惯性叠权（抗噪）**、**异源爆发叠权（破茧）**、**漂移累积叠权**三套分支逻辑。
- 强制防御熔断器：未成年人防护、成瘾打断、茧房破除；底层阈值硬编码，业务 A/B 测试平台无权修改。
- 商业分发预埋接口：接收叠权之后纯净推荐结果，支持外挂商业分发子模块；**商业逻辑严禁污染立体意图结构与历史惯性权重池，仅作用于最终输出展示层**。

## 二、核心模块级架构设计（七大模块）

### 模块 1：实时行为接入层（Action Gateway）

- 核心职责：接收客户端流式上报的用户微动作；做脏数据过滤、反刷量校验，统一全局时间戳基准。
- 输入：原始行为埋点数据流；可选入参`external_intent_contract = None`
- 输出：标准化`Action_Sequence`行为序列，透传外部意图契约向下游。

> 
> 冷启动分支（全新用户，无历史惯性权重池）

1. 用户无历史行为，也无`external_intent_contract`：使用系统预置的泛化探索因子，输出广谱多样性候选；不触发异源爆发逻辑，优先收集用户首批行为填充行为队列。
2. 用户无历史行为，但携带`external_intent_contract`：直接以搜索传入意图契约初始化立体意图结构，快速建立初始偏好。

### 模块 2：KC‑MHA 多因子意图感知层（改造自 Transformer Encoder）

> 
> 范式约束：训练阶段五路因子头投影矩阵 Wq/Wk/Wv **施加子空间正交损失**，隔离各因子语义空间，避免信号互相混杂；正交约束仅作用于本感知层；下游叠权阶段允许因子耦合叠加。
> 改造逻辑：抛弃文本自回归生成能力；将 Transformer 自注意力从「token‑token 关系建模」迁移至「用户行为‑意图因子关系建模」。

五路因子头定义：

- Head_Product（产品联动）：识别物品上下游关联（例：点击手机壳，推导对应手机型号）
- Head_Causal（因果动机）：挖掘行为背后的诉求动机（例：购买跑鞋，推导健身运动诉求）
- Head_Logic（逻辑偏好）：长期认知推断；区分偶然行为与用户固有偏好。
- Head_Emotion（情绪细分）：基于停留、滑动节奏识别：冲动、焦虑、探索跨域等情绪状态。
- Head_Decay（时间表征头）：输出行为序列内部的时序重要性表征；**注意：本头仅产出时序表征，不等于最终打分衰减系数；最终衰减交由状态流演化引擎二次计算。**

处理分支：

1. 仅行为输入：由`Action_Sequence`完整计算得到原始因子矩阵。
2. 同时存在`external_intent_contract`：将搜索侧意图矩阵做维度对齐，与行为序列产出因子矩阵做加权融合，生成最终**立体意图结构（3D Intent Structure）**。

输出：立体意图结构、各路因子置信度特征图。

### 模块3：状态流演化引擎（微状态机，比较只读 / 老化写入分离）
>范式判定规则：
异源突变判定依据：**当前立体意图结构表征 VS 历史惯性权重池累积表征的向量相似度**。
增加最小观测窗口保护：必须收集到N条有效新行为之后，才允许评估异源突变；**禁止单条点击行为直接触发异源爆发**，降低误触。

>历史惯性权重池老化遗忘策略：
- 逻辑强制拆分：
  1）相似度比对、状态信号输出属于**只读操作**，不修改任何持久化状态；
  2）惯性池老化遗忘属于**独立写入操作**；只读比对完成、输出状态信号之后，才执行老化更新；
- 各意图维度置信度随时间执行渐进式遗忘；长时间不再触发的意图维度置信度自然衰减回落；**不会直接清空全部历史，只是逐步降低历史基线影响力；冷启动新用户跳过老化逻辑**。
>🔒合规硬约束：未成年人账号，防御闸门相关标记状态**永久不参与老化遗忘，不允许随时间自动失效**；防沉迷、情绪因子屏蔽状态一旦判定，不会因为惯性池老化而消失。

- 核心职责：
  1. 接收立体意图结构，读取历史惯性权重池基线（只读，不修改）；
  2. 计算表征相似度，结合最小观测窗口校验；输出状态信号：
     - `INERTIA`同源：行为与历史基线方向一致
     - `DRIFT`意图漂移：出现新方向，但尚未达到爆发阈值
     - `HETEROLOGOUS`异源突变：行为显著脱离历史基线
  >偏移态对应`DRIFT`，冲突态对应`HETEROLOGOUS`。
  3. 【只读阶段完成后】执行独立的惯性池老化写入逻辑；未成年人账号仅做普通意图维度老化，**防御闸门标记状态完全跳过老化流程**。

### 模块 4：双轨叠权收敛层（多维叠权核心）

1. **确定性惯性叠权（同源 INERTIA）**
触发条件：连续行为方向高度一致。
执行：放大当前各路意图置信；压制孤立误触噪声；历史惯性权重池做增量累积更新。
2. **DRIFT 意图漂移叠权**
触发条件：行为出现新方向，但未抵达异源爆发阈值。
执行：仅累积异源信号，**不接管主排序流，维持原有推荐主体不变**。
3. **异源爆发叠权（破茧 HETEROLOGOUS）**

> 
> 修正原 “暴力全部清零” 逻辑：
> **不会全局清空全部历史惯性权重；仅对发生突变的意图维度，抑制该维度的历史惯性，放大异源新信号；其余无关意图维度完整保留原有惯性权重。**
> 触发条件：相似度低于阈值，并且满足最小观测窗口。
> 执行：突变维度异源信号指数抬升；历史惯性池仅针对突变维度做衰减，其余维度维持；完成后更新历史惯性权重池。

### 模块 5：底层强制防御闸门（业务不可修改）

1. 未成年人链路防护

- 识别未成年账号，直接屏蔽`Head_Emotion`情绪成瘾因子参与叠权计算；
- **压制异源爆发叠权放大倍率**，即便出现跨域行为，信息流不会发生剧烈翻转；异源仅允许教育科普类范畴生效。

2. 茧房清道夫

- 连续 20 次结果同源命中同一大类，则强制插入少量跨域陌生内容；
- 约束：跨域内容设置权重上限，仅做补充注入，不接管首页主体排序，避免大量无关内容刷屏。

3. 沉迷崩溃态熔断

- 检测长时间高频同质化消费行为；主动提升茧房清道夫注入比例，可联动上层做使用时长提示。

> 
> 所有阈值硬编码底层，业务 AB 测试平台不可篡改。

### 模块 6：输出网关（纯净结果输出点，商业分发前置点）

> 
> 契约约束：本层输出的`3D Intent Structure`立体意图结构为纯净状态，**对外接口、双流联动全部取自本层；商业分发仅复制一份结果副本做展示加工，绝不修改原始状态表征**。
> 输出结构化结果，附带完整 Debug 审计信息；立体意图结构可对外导出；若存在外部搜索契约输入，输出元数据中标记该来源。

### 模块 7：商业分发预埋子层（可选开关开启）

> 
> 仅接收输出网关的纯净结果副本，只做展示层插入商业标的物；禁止回写、污染立体意图结构、历史惯性权重池。
> 职责：复用体系内意图表征做商业库语义召回，执行柔性降权；商业标物强制`<sponsored>`打标；不允许挤占头部核心推荐位。

## 三、工况判定与系统行为

1. **稳态 INERTIA**：用户行为清晰稳定，惯性叠权生效，推荐匹配当下真实意图。
2. **偏移态 DRIFT（意图漂移）**：出现跨领域行为，但未到达爆发阈值；仅累积异源信号，主推荐流不做颠覆。
3. **冲突态 HETEROLOGOUS（异源爆发）**：满足观测窗口 + 相似度阈值；突变维度切换为主导信号，信息流局部重构；非突变维度保持历史偏好。
4. **冷启动态**：新用户，行为样本不足；输出广谱多样性内容；有外部搜索意图契约则优先使用该契约初始化。
5. **崩溃态**：高频长时间同质化消费；防御闸门介入，加强跨域内容注入，触发健康提示。

## 四、架构固有取舍说明（预印本附件，评审防御）

1. **算力代价**：多路因子实时序列计算，算力开销显著高于传统离线标签查表；大厂选择静态标签本质是算力妥协。
2. **情绪识别噪声**：仅依靠点击、停留、滑动等浅层埋点反推用户情绪，天然存在误判；阈值需要大量数据迭代调优。
3. **异源爆发两难**：阈值过低容易发生信息流震荡；阈值过高无法打破信息茧房；依靠最小观测窗口缓解，但无法完全消除误触发可能性。
4. **双流信号冲突取舍**：当外部传入`external_intent_contract`（搜索意图）与用户长期行为基线互相冲突时，叠权层执行加权融合，不存在绝对优先一方，需要工程调优融合系数。
5. **最小观测窗口权衡**：窗口设置偏大，响应新需求会变慢；窗口偏小更容易误触发异源爆发，属于固有权衡。
6. **惯性池老化权衡**：遗忘速率过快容易丢失长期用户偏好；遗忘过慢，旧偏好难以被新行为覆盖。
7. **商业分发隔离约束**：商业模块仅为外挂可选组件，关闭后整套推荐链路完全不受商业化逻辑影响。

## 五、可参考伪代码

```
def kc_trsf_tj_recommend(user_id, action_sequence, external_intent_contract = None, commercial_mode=False):
    # 1. KC‑MHA多因子感知层，支持外部搜索意图契约注入
    raw_factor_matrices = KCMHA_Factor_Extractor(action_sequence)

    # 双流合一：融合搜索侧传入的意图契约
    if external_intent_contract is not None:
        threeD_intent_structure = fuse_intent(raw_factor_matrices, external_intent_contract)
    else:
        threeD_intent_structure = raw_factor_matrices

    # 2.状态流演化引擎：只读比对（计算状态信号）与老化写入做物理分离
    # 2‑1 只读阶段：仅读取历史惯性池，计算状态信号，不修改持久化数据
    state_signal = StateEngine.compare_history_readonly(user_id, threeD_intent_structure)
    # 2‑2 独立写入阶段：执行惯性权重池渐进老化；未成年人账号防御标记禁止老化失效
    StateEngine.apply_inertia_pool_aging(user_id, is_minor_flag=is_minor(user_id))

    # 3.双轨叠权收敛
    final_intent_weights = {}
    if state_signal == "INERTIA":
        final_intent_weights = DeterministicStacking(threeD_intent_structure)
    elif state_signal == "DRIFT":
        final_intent_weights = DriftAccumulateStacking(threeD_intent_structure)
    elif state_signal == "HETEROLOGOUS":
        # 仅突变维度抑制历史惯性，其余维度保留
        final_intent_weights = HeterologousBurst(threeD_intent_structure, user_id)

    # 4.多因子召回候选池
    candidates = VectorDB.recall_by_multi_factors(final_intent_weights)

    # 5.底层强制防御闸门
    if is_minor(user_id):
        candidates = DefenseGate.filter_minor(candidates)
        final_intent_weights = DefenseGate.mask_emotion_factor(final_intent_weights)
        # 压制未成年人异源爆发幅度
        final_intent_weights = DefenseGate.restrict_hetero_gain(final_intent_weights)

    # 6.输出网关，输出纯净结果副本
    pure_output = {
        "recommend_list": rank_by_weights(candidates, final_intent_weights),
        "debug_state": state_signal,
        "burst_reason": "HETEROLOGOUS_DETECTED" if state_signal == "HETEROLOGOUS" else None,
        "intent_source": "search_fused" if external_intent_contract else "behavior_only",
        "3D_intent_structure": threeD_intent_structure.tolist()
    }

    # 7.可选商业分发子层（仅加工副本，不修改pure_output原始数据）
    if commercial_mode:
        display_output = CommercialDistributionGate(pure_output)
        return display_output
    return pure_output
```
