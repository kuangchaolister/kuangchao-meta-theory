# 狂潮・元理论架构分析-记忆系统原创｜M0‑Composite 六层可控分层记忆系统【元理论 v2.0‑public推演｜原创组合架构】

## 材料一｜M0‑Composite 设计摘要


# 第 0 章 设计摘要

## 要解决的问题

M1‑M5 历代记忆范式存在共有机理缺陷：记忆内核只做格式合法性校验，**不做业务语义真伪校验**；错误记忆一旦落盘持久化，可以经由检索‑推理‑再写入形成同源自噬（自污染放大）闭环，逐步滑向偏移、冲突、静默业务污染态。
部分范式依赖后台静默 LLM 抽取生成记忆，抽取幻觉可在用户无感知情况下持续注入记忆库；部分范式缺少版本回滚、矛盾识别隔离手段，污染发生后处置成本高。

## M0‑Composite 核心方案

M0‑Composite 六层可控分层记忆系统，萃取 M1‑M2‑M3‑M4‑M5 各范式可取能力，引入**五道隔离挡板作为风险抑制层**（挡板仅抑制缺陷向上传导，不能理论上彻底根除底层机理缺陷）。
顶层强制约束：**禁用后台静默自动抽取记忆；所有记忆写入必须来自 Agent 显式 tool‑call 调用或者人工标注**。
写入通路强管控链路：
`Agent工具请求接入模块 → 写入校验网关挡板 → 时序‑版本管控模块（COW写时复制、签发双时间戳） → 六层存储调度模块`

### 六层存储分层设计依据

按照 4 个维度进行拆分：读写访问频率、存储介质、数据保留生命周期、一致性约束。
六层存储：

1. 工作记忆页：短期上下文窗口
2. 召回缓存层：高频最近记忆高速缓存
3. 事实图谱层：Episode 事件 + Fact 时序事实存储
4. 记忆向量库：**与业务知识库物理隔离独立向量存储**
5. 归档冷存储：低频长期记忆归档
6. 版本审计层：COW 写时复制快照、变更 diff 记录，支持版本回滚

> 
> 若进行多层合并，会带来：冷热数据资源争抢、版本回溯能力丢失、业务记忆与知识库混库风险、高频查询被低频归档数据拖累等负面后果。

### 五道隔离挡板以及防护目标

1. **写入校验网关挡板**：抑制 Agent tool‑call 传入幻觉记忆直接落盘。
2. **禁止后台静默抽取挡板**：抑制 LLM 后台隐式抽取带来的幻觉记忆落盘。
3. **存储物理隔离挡板**：记忆向量库与业务知识库物理隔离，杜绝混库污染。
4. **COW 版本‑diff 挡板**：解决原地改写不可撤回、无历史版本的缺陷，支持版本回滚；快照回放仅激活已有污染，回放本身不会制造新错误。
5. **冲突队列挡板**：识别命中的矛盾记忆不自动标记失效，送入冲突队列等待复核；规避 LLM 自动判定失效带来误判污染。

## 本架构明确不做的事情（边界声明）

1. 所有隔离挡板仅为**风险抑制机制，不能彻底根除继承自 M1‑M5 的底层机理缺陷**；挡板配置错误、LLM 漏检、绕过网关直改底层存储，缺陷依然向上暴露。
2. 内核不会自动消解事实矛盾；网关识别命中的矛盾送入冲突队列，交由上层二次 LLM 复核或人工复核。
3. **内核不接管操作系统底层存储权限隔离**；底层存储被外部进程旁路篡改时，篡改操作不流过内核，审计模块无采集机会。
4. 内核无内置 LLM 调用限流、无存储硬容量上限；资源管控属于上层【外部自研增补】。
5. **内核不提供开箱即用跨层事务级批量清除接口**；跨存储污染清除需要上层封装分步工作流，清除不可逆。

## 核心设计取舍总览

以**写入校验网关单点开销、写入链路增加延迟、六层存储带来异步同步复杂度**，换取记忆写入链路可管控、全链路可审计、记忆变更支持版本回滚的能力。

## 材料四｜失败模式优先级摘要表


# 0.3 高优先级失败模式摘要

> 
> 排序说明：Top3 为人工确定优先级；次级风险仅罗列编号，详细机理见正文各模块、工况、隐患章节。

### Top‑1 写入校验网关 LLM 漏检

- 触发条件：Agent 通过 tool‑call 传入格式合法但业务事实错误 / 幻觉记忆；写入校验网关 LLM 发生漏检，错误记忆放行落盘进入六层存储。
- 发生概率：高（LLM 幻觉漏检属于网关固有机理现象）
- 检测手段：网关输出二次复核（【外部自研增补】上层业务）、业务指标命中率异常告警
- 止损手段：冲突队列事后追溯、COW 快照版本回滚
- 责任归属：**范式本体机理缺陷；二次复核不属于内核原生能力，属于外部自研增补**

### Top‑2 COW 快照链污染后执行版本回放

- 触发条件：快照链已经存在被污染历史版本；业务执行版本回滚回放操作；回放会把历史污染记忆重新激活写入各层存储；**回放本身不会制造新错误，仅激活已有污染**。
- 发生概率：中（取决于业务是否使用回滚能力、快照链是否已经被污染）
- 检测手段：快照回放前置校验（【外部自研增补】上层业务）、上层业务指标异常监控
- 止损手段：回放前阻断风险快照；回放完成后做业务二次校验
- 责任归属：**范式本体机理缺陷；回放前置校验属于外部自研增补**

### Top‑3 底层存储被外部进程旁路篡改

- 触发条件：外部进程绕过 M0‑Composite 全部内核模块，直接修改底层图数据库 / 向量库 / 冷归档对象存储；篡改操作不流过内核，**审计模块无采集机会**。
- 发生概率：低‑中，取决于底层存储操作系统权限管控水平
- 检测手段：底层数据集哈希定期比对检测告警（【外部自研增补】上层业务）
- 止损手段：触发告警，从安全冷归档备份重建数据
- 责任归属：**范式本体感知边界 + 载体层访问控制缺口；检测能力属于外部自研增补**

### 次级风险清单（正文完整展开，此处仅索引）

1. 归档‑降级策略同源偏置风险
2. 六层存储层间晋升‑降级流转同源偏置，跨层污染传播风险
3. RRF 检索融合权重同源偏置风险
4. 多存储组件异步同步，长时间视图不收敛
5. 冲突队列持续堆积，缺少自动消解
6. 写入校验网关单点宕机，写入通路整体中断
7. 内核仅支持按 version_id / 来源定位，无开箱即用跨层事务级批量清除接口
8. Agent 忘记调用记忆写入 tool‑call，产生记忆漏写
9. COW 快照、冲突队列、归档记忆持续累积带来存储膨胀
10. 隔离挡板配置错误，下层继承 M1‑M5 缺陷向上暴露
11. 多重条件叠加，形成完整同源自噬自演化闭环

> 
> 排序依据说明：

1. Top‑1 网关漏检：发生概率最高，一旦放行影响全部六层存储，影响面最大；
2. Top‑2 快照污染回放：**具备不可逆放大特性**，回滚操作会批量复现历史污染；
3. Top‑3 底层旁路篡改：故障完全不经过内核，无内核审计事件，检测难度最高。

> 
> 所有次级风险均依赖上层业务 / 管控面外部自研增补做监控、告警、处置；内核本体无法彻底消除。

# 修改后完整版｜0.4 接口契约 + 0.5 核心业务时序图



## 0.4 接口契约

> 
> 约定：

- `🔹内核原生接口`：M0‑Composite 内核直接提供；
- `🔸外部自研增补接口`：上层业务管控模块实现，不属于内核本体；
- `version_id`：版本全局唯一；`agent_id/user_id`会话标识；`evidence_chain`原始证据片段数组；
- 返回统一包装结构：`{code:int,msg:string,data:any}`；code=0 成功；非 0 为业务异常；IO 异常直接抛底层存储异常。

### 🔹内核原生接口集合

#### 1. write_memory（记忆写入入口，唯一写入入口）

> 
> 归属：Agent 工具请求接入模块 → 透传给写入校验网关；**禁止绕过本接口直接写底层存储**

```
入参：
{
  agent_id: string,
  user_id?: string,
  payload: {
    fact_content: string,
    fact_type: enum["episode","fact"],
    evidence_chain: string[], //原始证据片段，不可为空
  },
  meta?: Record<string,any>
}
前置条件：
1. agent_id 非空；
2. evidence_chain 不为空数组；
3. 禁止后台静默调用：调用源必须是 Agent tool‑call / 人工标注；内核不提供后台自动抽取触发器。

出参：
{
  code:int,
  msg:string,
  data:{
    status:enum["passed_to_gate","enter_conflict_queue"],
    version_id?:string, //passed_to_gate才返回；进入冲突队列无version_id
    conflict_task_id?:string //enter_conflict_queue才返回
  }
}

后置条件：
‑status=passed_to_gate：载荷通过网关初筛，进入时序‑版本管控，后续流向六层存储调度；生成version_id；
‑status=enter_conflict_queue：网关识别命中矛盾，不写入存储；进入冲突事件队列，返回conflict_task_id；

异常：
‑400：入参格式非法；
‑503：写入校验网关服务不可用；写入通路整体阻断，查询不受影响。

越界说明：
内核不校验payload业务事实真伪；仅做格式、非空校验；网关LLM存在漏检风险；网关漏检的错误记忆会完整向下落盘。
```

#### 2. get_memory（记忆查询 & 渐进披露读取入口）

> 
> 归属：Agent 工具请求接入模块 →混合检索 RRF 融合模块 →渐进式披露组装模块

```
入参：
{
  agent_id:string,
  user_id?:string,
  query_text:string,
  filter?:{
    invalid_at_filter:bool=true, //默认开启，过滤已标记失效fact
    rrf_weight_override?:{bm25:number,vector:number,graph:number} //同源侧可传入权重配置
  },
  need_full_episode:bool=false //false=仅高层摘要；true=显式recall，返回完整episode/fact
}

前置条件：agent_id非空

出参：
{
  code:int,
  msg:string,
  data:{
    memory_fragments:[
      {
        content:string,
        source_type:enum["summary","episode","fact"],
        version_id:string,
        evidence_chain:string[],
        create_ts:{biz_time:string,sys_write_time:string} //双时间戳
      }
    ]
  }
}

后置条件：
‑need_full_episode=false：仅返回高层摘要片段；
‑need_full_episode=true：返回完整episode/fact记忆片段；
‑片段携带version_id、证据链、双时间戳元信息。

异常：
400入参非法；503检索后端IO故障。

越界说明：
RRF权重可被同源侧传入带来同源偏置；内核不校验返回记忆业务事实真伪；底层存储被旁路篡改会原样返回篡改内容。
```

#### 3. conflict_queue_get_task（获取冲突队列待复核任务）

> 
> 归属：冲突事件队列模块

```
入参：{conflict_task_id?:string,agent_id?:string,page_size:int}
出参：
{
  code:int,
  data:{
    task_list:[
      {
        conflict_task_id:string,
        origin_write_payload:object,
        evidence_chain:string[],
        create_sys_time:string
      }
    ]
  }
}
前置条件：无；可按task_id单条查询，或按agent_id批量分页查询
异常：503队列存储IO异常
越界说明：仅返回网关识别命中矛盾的条目；网关漏检的矛盾不会进入该队列。
```

#### 4. conflict_queue_review_resolve（冲突任务复核决议回写）

> 
> 归属：冲突事件队列模块 →回写给时序‑版本管控模块

```
入参：
{
  conflict_task_id:string,
  resolve_action:enum["write_pass","mark_invalid","discard"],
  meta?:Record<string,any>
}
resolve_action释义：
write_pass：放行，走完整写入链路落盘；
mark_invalid：标记失效，不写入业务记忆；
discard：直接丢弃该条目。

出参：{code:int,msg:string,data:{version_id?:string}}

前置条件：conflict_task_id必须存在于冲突队列。
后置条件：
write_pass：重新进入时序‑版本管控生成version_id，写入六层存储；
mark_invalid / discard：不生成业务记忆，任务标记完结。

异常：404 task_id不存在；503 IO异常。
越界说明：复核逻辑由外部业务实现；内核只执行决议分发。
```

#### 5. snapshot_rollback（COW 快照版本回滚回放接口）

> 
> 归属：时序‑版本管控模块

```
入参：
{
  agent_id:string,
  target_version_id:string //回滚目标快照version_id
}
```

> ⚠️中立声明：基于狂潮元理论 v2.0‑public 完成中立架构拆解；设置隔离挡板不等于可以 100% 消除底层子模块固有缺陷，仅做风险抑制；挡板失效时子模块缺陷仍可向上暴露。

## 三层边界划分

①范式本体（M0‑Composite 六层可控分层记忆系统内核）

> 
> 【组合架构原生】模块清单：
> Agent 工具请求接入模块、写入校验网关模块、时序‑版本管控模块、六层存储调度模块、混合检索 RRF 融合模块、渐进式披露组装模块、冲突事件队列模块、全链路审计模块。
> 六层存储（【组合架构原生】存储层）

1. 工作记忆页：短期上下文窗口
2. 召回缓存层：高频最近记忆高速缓存
3. 事实图谱层：Episode 事件 + Fact 时序事实存储
4. 记忆向量库：**与业务知识库物理隔离独立向量存储**
5. 归档冷存储：低频长期记忆归档
6. 版本审计层：COW 写时复制快照、变更 diff 记录，支持版本回滚

> 
> 核心一等公民：Episode 事件；每条记忆绑定原始证据片段、version_id、网关签发双时间戳（业务事件时间、系统事务写入时间）。
> 关键通路特征：
> ‑**硬性顶层规则：禁止后台静默自动抽取记忆；所有记忆写入必须来自显式触发源：Agent 工具调用 / 人工标注；Agent 拥有记忆操作发起权，落盘、校验、时序、版本完全由内核网关管控。**
> ‑写入通路：Agent 工具请求接入 →写入校验网关（LLM 一致性校验、矛盾初筛） →时序‑版本管控签发时间戳，生成 COW diff 快照 →六层存储调度模块分发写入到：召回缓存、事实图谱层、独立记忆向量库、归档冷存储、版本审计层；**两条互斥分支：①网关识别命中矛盾：条目不入存储，仅送入冲突事件队列；②网关漏检未识别的矛盾：随正常写入链路落盘，后续可被同时召回。**
> ‑查询读取通路：混合检索 RRF 融合模块（向量 + BM25 + 图多跳遍历；接口默认携带网关签发时间戳过滤过期`invalid_at`事实） →渐进式披露组装模块：优先高层摘要送入上下文；需要细节才显式召回完整 Episode/Fact；输出记忆片段给到 Agent 推理上下文。
> ‑隔离挡板设计（组合架构原生，用于封闭 M1‑M5 继承来的子模块缺陷）：

1. 写入校验网关挡板：Agent 工具写入请求不能直接透传到存储层；做矛盾、事实一致性初筛，抑制 Agent 幻觉直接落盘风险（隔离 M1 工具幻觉直写缺陷）。
2. 禁止后台静默抽取挡板：关闭隐式对话扫描抽取，规避 M2/M3/M5 静默 LLM 抽取幻觉落盘。
3. 存储物理隔离挡板：记忆向量库与业务知识库两套物理独立存储，禁止混库，隔离 M4 混库缺陷。
4. COW 版本‑diff 挡板：每条变更留存快照 diff，支持回滚；修复 M5 rollout 只追加不可撤回、MEMORY.md 原地改写无版本的缺陷。
5. 冲突队列挡板：检测到矛盾事实**不会自动标记失效**，送入冲突队列等待复核；规避 M3 自动判定失效带来误判污染。

> 
> ⚠️挡板约束：挡板属于风险抑制机制，**不是根除机理缺陷；挡板配置错误、LLM 漏检、挡板绕过，下层子模块缺陷依然可以向上传导到上层 Agent。**

②可替换外部组件：上层 Agent 编排业务；**校验网关 LLM 输出复核、RRF 检索调参与同源偏置校验、冷归档生命周期治理、冲突队列人工 / 二次 LLM 复核、存储层签名防篡改、大规模运维监控告警、归档‑降级策略复核、存储层间流转规则复核、跨层污染批量清除封装全部属于【外部自研增补】**。

③外部载体环境：业务 LLM、校验网关独立 LLM 实例；图数据库、向量数据库、对象冷归档存储；载体层缺陷：LLM 幻觉、数据库 IO 故障、网络抖动、存储磁盘损坏、组件异步同步延迟，属于【外部依赖・载体层】；内核不接管底层数据库、操作系统权限。

背景：
M0‑Composite 定位：`Agent = Agent运行时 ⊕ M0‑Composite六层可控分层记忆系统`

> 
> 范式核心特征：

1. 能力萃取来源：
‑M1：冷热分层、工作页 / 缓存 / 冷归档、Agent 显式工具调用发起记忆操作；增设校验网关挡板，阻止请求直接落盘。
‑M2：服务化中间件形态、标准化 SDK、user/agent_id 会话隔离；关闭后台静默抽取挡板。
‑M3：Episode 一等公民、Fact 有效期标记、向量 + BM25 + 图混合检索 RRF；增设挡板：关闭 LLM 自动失效判定，矛盾送入冲突队列；检索接口默认时间过滤。
‑M4：向量语义召回；增设挡板：记忆向量库与业务知识库物理隔离，禁止混库。
‑M5：渐进式披露加载；增设挡板：破除 “仅会话关闭提炼” 限制，可随时触发记忆写入；引入 COW 写时复制版本快照 diff，支持记忆回滚。
2. 双时间戳机制：业务事件时间、系统事务写入时间，**网关未被攻陷前提下上层 Agent、业务层不可伪造篡改；网关自身被攻陷属于中心控制点单点失效场景。**
3. COW 写时复制版本审计层：每次记忆变更自动生成快照 diff；支持版本回溯回滚；完整记录每条记忆变更链路；**COW 快照链可被错误记忆污染；执行版本回滚回放，会重新激活历史污染源；回放机制本身不创造错误；快照被污染源头分两类：①网关漏检穿透挡板写入污染记忆；②旁路篡改底层存储引入污染。**
4. 冲突处理机制：网关检测事实矛盾，**识别命中的矛盾条目不落盘，送入独立冲突事件队列等待二次 LLM 复核或人工复核；网关漏检未识别的矛盾记忆会随正常链路落盘；复核通过之后才执行失效标记写入存储。**
5. 审计：记忆增删改查、版本变更、冲突事件全部留存审计日志；每条持久化记忆绑定原始证据片段。**旁路篡改操作不经过内核任何模块，审计模块无采集机会，故内核审计日志中无对应记录【范式本体感知边界，非审计模块功能缺失】。**
6. 六层存储调度能力：支持按来源、version_id 定位记忆条目；**无开箱即用跨层批量清除接口；清除需要多存储分别执行，无统一事务级跨层原子清除，清除不可逆；层间晋升‑降级流转必须携带 version_id，流转规则配置可同源偏置，存在跨层污染传播风险。**
7. 固有风险来源：
‑校验网关依赖 LLM，存在漏检幻觉，错误记忆依然有概率穿透挡板落盘；
‑归档‑降级元数据规则可同源偏置，造成错误记忆高频留存，正确记忆被误归档；
‑六层存储层间晋升‑降级流转配置可同源偏置，带来跨层污染传播；
‑多存储组件（缓存 / 图谱 / 向量库 / 冷存）异步同步延迟，带来多存储视图不一致；
‑RRF 混合检索调参敏感，存在检索同源偏置风险；
‑COW 快照链若被污染，快照回放会重新激活污染源；回放本身不生成错误，仅激活已存在污染；
‑Agent 侧必须显式调用工具写入记忆；Agent 忘记调用则记忆不会被持久化；
‑网关作为中心控制点，存在单点风险；挡板配置错误或被绕过，下层子模块缺陷向上传导；
‑多形态记忆跨层扩散后，缺少内核原生跨层批量清除能力，污染清除不可逆。

> 
> 【分析抽象・非原生说明】抽象 “六层总调度器” 仅用于建模推演，现实逻辑分散在内核各个模块，不存在独立物理进程。
> v2.0 补充视角：M0‑Composite 属于**带多层风险抑制挡板的多存储自演化信息系统**。
> 1）写入回流路径：Agent 幻觉生成错误记忆 →发起显式工具写入请求 →校验网关 LLM 漏检 →错误记忆穿透挡板，经过时序版本管控落盘到六层存储；后续检索召回，错误记忆送入 Agent 推理上下文，形成同源自噬闭环。
> 2）快照回流路径：COW 版本链内存在污染快照；执行版本回滚回放，快照回放重新激活历史污染源，错误记忆重新进入各层存储，再被检索送入推理上下文；回放本身不制造错误，仅激活已有污染。
> 3）层间流转回流：同源偏置的晋升‑降级规则，将错误记忆跨层迁移扩散至六层不同存储形态，扩大污染范围。
> 4）挡板失效路径：挡板配置错误 / 绕过网关直接操作底层存储；下层继承自 M1‑M5 的固有缺陷向上暴露。
> 5）载体旁路回流：**旁路篡改操作不经过内核任何模块，审计模块无采集机会，故内核审计日志中无对应记录【范式本体感知边界，非审计模块功能缺失】。**
> **同源自噬成立的前提：错误记忆穿透挡板未被过滤、预审、标记隔离；并且实际流入 Agent 推理上下文；任一隔离 / 挡板机制生效，则抑制同源放大闭环，但不能做到理论上彻底根除。**

## 步骤 1：模块边界定格 + 权限原子化协议扫描【v2.0 复审项】

> 
> 权限原子化扫描 6 维度：核心职责｜私有状态｜可公开状态｜允许接收输入｜允许发出输出｜越界黑名单

### M0‑Composite 内核核心模块清单

1. **Agent 工具请求接入模块【组合架构原生】**
接收 Agent 侧通过 tool‑call 发起的记忆增 / 删 / 改 / 查询请求；接收人工标注写入请求；携带`agent_id/user_id`；对请求做格式解析；**不直接访问任何底层存储；所有写入请求向下转发至写入校验网关模块**。

> 
> 🔍权限原子化扫描
> ‑核心职责：接收并解析 Agent 工具调用、人工标注记忆操作请求；格式校验；转发写入请求至校验网关；查询请求下发混合检索模块。
> ‑私有状态：当前会话`agent_id/user_id`；工具请求会话上下文。
> ‑可公开状态：agent_id/user_id 会话标签。
> ‑允许接收输入：Agent tool‑call 记忆操作请求；人工标注记忆条目；agent_id/user_id 标识。
> ‑允许发出输出：解析后标准化记忆写入请求；标准化记忆查询请求；格式非法拒绝事件。
> ‑越界黑名单：**仅做协议解析转发；不做业务事实真伪校验；Agent 可以生成幻觉记忆内容；无法绕过 / 跳过内核直接访问底层存储（取决于上层部署权限配置）；不执行任何记忆落盘逻辑。**

2. **写入校验网关模块【组合架构原生｜写入通路核心挡板】**
接收标准化记忆写入请求；执行 LLM 驱动一致性、事实矛盾初筛；绑定原始证据片段；**两条互斥分支：①网关识别命中矛盾：条目不入存储，仅送入冲突事件队列；②网关漏检未识别的矛盾：随正常写入链路向下流转落盘。**校验通过的请求向下送时序‑版本管控模块。

> 
> 🔍权限原子化扫描
> ‑核心职责：写入通路风险抑制挡板；LLM 一致性与矛盾初筛；绑定原始证据片段；识别命中的矛盾送入冲突队列；放行合法记忆写入请求；漏检的矛盾会随正常链路向下流转。
> ‑私有状态：校验网关 LLM 配置；矛盾检测规则配置；校验中间上下文。
> ‑可公开状态：校验 LLM 配置、矛盾检测规则配置。
> ‑允许接收输入：标准化记忆写入请求（来自 Agent 工具请求接入模块）。
> ‑允许发出输出：校验放行的记忆写入载荷；识别命中的矛盾记忆条目（送入冲突事件队列）；校验拒绝事件；网关异常事件。
> ‑越界黑名单：**依靠 LLM 做一致性校验，存在幻觉漏检，错误记忆、未识别的矛盾可以穿透挡板向下流转；仅做初筛，不能做到 100% 识别事实矛盾；不访问底层存储；无法阻止上层构造完全自洽但客观错误的记忆条目。【挡板为抑制机制，非根除缺陷】**

3. **时序‑版本管控模块【组合架构原生】**
接收校验网关放行的写入载荷；**网关未被攻陷前提下统一签发两套不可伪造时间戳：业务事件时间、系统事务写入时间；网关自身被攻陷，时间戳可被篡改。**执行 COW 写时复制，生成变更 diff 版本快照，写入版本审计层；生成带`version_id`的标准记忆条目，下发六层存储调度模块。

> 
> 🔍权限原子化扫描
> ‑核心职责：网关正常运行下统一签发双时间戳；COW 写时复制，生成变更 diff 与 version_id；管控版本链；输出带完整元数据的记忆条目。
> ‑私有状态：版本自增 ID 序列；事务时间戳生成上下文；COW 快照 diff 中间数据。
> ‑可公开状态：版本链查询接口。
> ‑允许接收输入：校验网关放行的记忆写入载荷。
> ‑允许发出输出：携带双时间戳、version_id、diff 快照的标准记忆条目；版本快照写入指令；版本链异常事件。
> ‑越界黑名单：**网关未被攻陷时上层不可伪造时间戳；若网关本身被攻陷，时间戳可被篡改；COW 快照只记录变更 diff，不校验记忆业务事实真伪；快照链可以被向下流转的错误记忆污染；回放快照仅重新激活已有污染源，回放本身不制造错误。**

4. **六层存储调度模块【组合架构原生】**
接收时序‑版本管控输出的标准记忆条目；**负责六层存储层间晋升‑降级流转判定；归档 / 降级决策规则、决策主体、触发阈值；层间流转强制携带 version_id；归档‑降级元数据规则可同源偏置；**按规则分发写入：工作记忆页、召回缓存层、事实图谱层、记忆向量库、归档冷存储、版本审计层；**记忆向量库与业务知识库物理隔离，禁止混写；处理多存储组件之间异步同步；接收查询指令调度各存储返回数据；支持按来源、version_id 定位记忆条目；无开箱即用跨层批量清除接口；清除需要多存储分别执行，无统一事务级跨层原子清除，清除不可逆。**

> 
> 🔍权限原子化扫描
> ‑核心职责：六层存储写入分发；**层间晋升‑降级流转调度；归档 / 降级决策；维护存储层之间异步同步逻辑；执行查询时调度多存储返回数据；强制隔离记忆向量库与业务知识库；支持按来源、version_id 定位记忆条目，无开箱即用跨层批量清除接口。**
> ‑私有状态：各存储组件同步状态；缓存淘汰、归档降级策略；层间流转配置；存储路由配置。
> ‑可公开状态：存储路由、缓存淘汰、归档降级、层间流转策略配置。
> ‑允许接收输入：带完整元数据标准记忆条目；来自混合检索模块的多存储查询调度指令。
> ‑允许发出输出：各存储组件写入指令；层间晋升‑降级流转指令；多存储原始查询结果集；存储异步同步滞后告警事件；存储 IO 异常事件。
> ‑越界黑名单：**只执行存储路由、层间流转、归档降级调度，不校验记忆业务事实真伪；归档‑降级、层间晋升降级规则配置可同源偏置，造成错误记忆跨层扩散；多存储之间为异步同步，会出现短暂多存储视图不一致；依赖底层载体数据库 / 对象存储可靠性；若部署权限配置不当，底层存储可被外部进程旁路篡改；支持按来源、version_id 定位，无内核原生跨层事务级批量清除接口，清除不可逆【范式本体感知边界 + 载体层访问控制缺口】。**

接收标准化记忆查询请求；**查询接口默认携带网关签发时间戳，自动过滤`invalid_at`过期 Fact；并行执行向量检索、BM25 检索、图多跳遍历；RRF 算法融合打分排序；输出融合原始结果集给到渐进式披露组装模块；检索排序配置可被同源侧传入。**

> 
> 🔍权限原子化扫描
> ‑核心职责：多源检索执行；默认时间过滤过期事实；RRF 结果融合排序；输出原始检索结果集。
> ‑私有状态：RRF 融合权重配置；检索过滤模板；查询上下文。
> ‑可公开状态：RRF 权重、检索过滤模板配置。
> ‑允许接收输入：标准化记忆查询请求。
> ‑允许发出输出：多源融合原始记忆结果集；检索异常事件。
> ‑越界黑名单：**不校验检索返回记忆条目业务事实真伪；RRF 权重配置可同源偏置，带来检索端同源偏置风险；仅做检索融合，不做事实校验；无法感知底层存储被旁路篡改的记忆内容。**

6. **渐进式披露组装模块【组合架构原生】**
接收混合检索模块融合结果集；执行渐进式披露逻辑：优先提取高层摘要送入 Agent 上下文；当 Agent 显式调用 recall 工具，才加载完整 Episode/Fact 细节；对记忆片段追加来源、version_id、证据元标记；组装送入 LLM 推理上下文。

> 
> 🔍权限原子化扫描
> ‑核心职责：渐进式披露；高层摘要优先推送；按需加载完整 Episode 细节；记忆片段附加元信息标记；组装推理上下文记忆片段。
> ‑私有状态：本次 Agent 实例已加载记忆元信息缓存。
> ‑可公开状态：渐进式披露策略配置。
> ‑允许接收输入：混合检索模块融合原始结果集；recall 显式细节读取指令。
> ‑允许发出输出：组装完成带元标记的记忆片段；披露策略异常事件。
> ‑越界黑名单：**原样输出检索返回的记忆内容，不校验业务事实真伪；不会自动消解多条记忆之间的事实矛盾；仅做组装、元标记，不修改记忆载荷本身。**

7. **冲突事件队列模块【组合架构原生】**
接收写入校验网关识别命中的矛盾记忆条目；持久保存矛盾原始载荷、证据链、版本元信息；提供队列读取接口，供给二次 LLM 复核或者人工复核；复核完成输出复核决议（放行写入 / 标记 invalid_at / 直接丢弃），回写给时序‑版本管控模块。

> 
> 🔍权限原子化扫描
> ‑核心职责：存储检测识别命中的矛盾记忆条目；保存完整原始证据与元数据；接收复核决议，回写至版本管控链路。
> ‑私有状态：冲突队列任务集合；队列状态上下文。
> ‑可公开状态：冲突队列查询接口。
> ‑允许接收输入：校验网关送入的识别命中的矛盾记忆条目；外部复核决议结果。
> ‑允许发出输出：队列待复核条目输出；复核决议回写指令；队列堆积告警事件。
> ‑越界黑名单：**仅存储与流转网关识别命中的矛盾条目；网关漏检的矛盾不会进入该队列；不自动做事实消解；复核逻辑交由外部；队列仅处理网关识别命中的矛盾。**

8. **全链路审计模块【组合架构原生】**
采集全链路事件：工具请求、校验网关判定、时间戳版本生成、六层存储写入、层间流转、检索查询、冲突队列出入队、复核决议；持久留存审计日志，包含原始证据片段元信息。

> 
> 🔍权限原子化扫描
> ‑核心职责：采集流过内核模块的记忆全链路操作事件；持久化完整审计日志。
> ‑私有状态：审计事件日志数据集。
> ‑可公开状态：审计日志只读查询接口。
> ‑允许接收输入：内核各模块上报的操作事件。
> ‑允许发出输出：审计日志查询结果；审计存储异常事件。
> ‑越界黑名单：**仅记录流过内核模块的事件；旁路篡改操作不经过内核任何模块，审计模块无采集机会，故内核审计日志中无对应记录【范式本体感知边界，非审计模块功能缺失】；不校验记忆业务事实真伪。**

## 步骤 2：两套核心流转链路拆解（双流模型 v2.0 严格逻辑分离）

> 
> 严格拆分：**写入变更通路；查询读取通路；冲突复核回写子通路；区分 Agent 请求层、网关管控层、六层持久存储层；禁止后台静默抽取写入通路。**

### 权限‑状态流（记忆信息数据流）

#### 通路 1：记忆写入变更通路（完整必经链路）

1. Agent 运行时 tool‑call 发起记忆写入 / 修改请求；或者人工标注提交记忆条目；携带 agent_id/user_id，送入 Agent 工具请求接入模块。
2. Agent 工具请求接入模块解析请求；**禁止直写存储，全部写入请求下发写入校验网关模块。**
3. 写入校验网关模块：执行 LLM 一致性、矛盾初筛；绑定原始证据片段。
   - 分支 A：**网关识别命中事实矛盾 → 送入冲突事件队列模块，不向下落盘；等待复核决议；走冲突复核回写子通路。**
   - 分支 B：**网关漏检未识别矛盾 / 校验放行 → 下发时序‑版本管控模块。**
4. 时序‑版本管控模块：**网关未被攻陷前提下签发业务事件时间、系统事务写入时间；COW 写时复制生成 diff、version_id；输出完整元数据标准记忆条目。**
5. 六层存储调度模块：**执行层间晋升‑降级、归档‑降级判定；分发写入到六层存储；记忆向量库严格物理隔离业务知识库；多存储执行异步同步；层间流转强制携带 version_id。支持按来源、version_id 定位记忆条目，无开箱即用跨层事务级批量清除接口。**
6. 全链路审计模块采集整条链路全部事件，留存审计日志。

#### 冲突复核回写子通路（分支 A 衍生）

1. 矛盾记忆条目驻留冲突事件队列模块；等待二次 LLM 复核 / 人工复核。
2. 输出复核决议：放行写入 / 标记 invalid_at / 丢弃。
3. 决议回写给时序‑版本管控模块，重新走版本生成→六层存储调度写入；审计记录复核全流程事件。

#### 通路 2：记忆查询读取通路

1. Agent 发起记忆查询 /recall 细节工具请求，送入 Agent 工具请求接入模块。
2. Agent 工具请求接入模块解析查询请求，下发混合检索 RRF 融合模块。
3. 混合检索 RRF 融合模块：**默认携带网关签发时间戳，自动过滤 invalid_at 过期事实；并行向量 / BM25 / 图多跳检索；RRF 权重融合排序；输出原始结果集。**
4. 渐进式披露组装模块：优先高层摘要送入上下文；Agent 显式 recall 才加载完整 Episode/Fact；追加来源、version_id、证据元标记；组装记忆片段送入 Agent LLM 推理上下文。
5. 全链路审计模块采集查询读取链路全部事件。

#### 公共旁路通路（载体层风险）

外部进程绕过整套内核全部模块，**直接对底层图数据库、向量库、冷归档对象存储做增删改；旁路篡改操作不经过内核任何模块，审计模块无采集机会，故内核审计日志中无对应记录【范式本体感知边界，非审计模块功能缺失】；篡改内容下一次检索直接被加载进入推理上下文。**

> ‑网关属于中心控制点；网关服务宕机则全部记忆写入通路中断。

3. **数据配权限【组合架构原生｜固有缺口】**

> 
> ❗固有缺口：
> ‑隔离：agent_id/user_id 逻辑会话隔离；**记忆向量库与业务知识库做到物理隔离；但底层存储权限配置不当，外部可旁路篡改底层库【范式本体感知边界 + 载体层访问控制缺口】。**
> ‑挡板仅做风险抑制：**网关校验格式合法≠业务事实正确；网关 LLM 可以漏检矛盾与幻觉记忆；网关漏检的错误记忆可以完整走完写入全链路；业务语义深度校验属于【外部自研增补】。**
> ‑RRF 检索融合权重、归档‑降级、层间流转配置可同源侧传入，带来检索、存储流转同源偏置风险。
> ‑内核审计只记录流过内核模块事件；**旁路篡改操作不经过内核任何模块，审计模块无采集机会，内核审计无对应记录【外部自研增补：底层存储篡改检测】。**

4. **一致就向前【组合架构原生｜格式契约，非业务一致性】**

> 
> ❗固有缺口：**工具请求格式合法、网关校验放行（含漏检放行），即可向下流转落盘；放行不等于业务事实正确；多条互相矛盾记忆可以同时持久化存入存储；内核不会自动消解矛盾；网关识别命中矛盾送入冲突队列等待复核；网关漏检的矛盾直接落盘，后续检索直接送入推理上下文。**

5. **能量带定义【组合架构原生｜存在缺口】**

> 
> ❗固有缺口：
> ‑内核原生没有 LLM 调用限流；没有六层存储总容量硬上限；COW 快照、冲突队列、归档记忆持续累积会带来存储膨胀；归档‑降级、层间流转、冲突队列无自动清理；大规模生命周期、资源管控全部属于【外部自研增补】。
> ‑校验网关、多存储同步、版本 diff、层间流转调度增加写入延迟；内核不做自动降级策略【项目实现缺陷，可上层增补】。

6. **状态要报备【组合架构原生｜部分缓解，存在缺口】**

> 
> ❗固有缺口：
> ‑流过内核模块的增删改查、版本变更、层间流转、冲突入队 / 复核，**内核原生完整留存审计日志。**
> ‑**旁路篡改操作不经过内核任何模块，审计模块无采集机会，故内核审计日志中无对应记录【范式本体感知边界，非审计模块功能缺失】。**
> ‑网关校验只做初筛；内核不校验记忆业务载荷真伪；完整深度业务校验属于【外部自研增补】；**内核支持按来源、version_id 定位记忆条目，无开箱即用跨层事务级批量清除接口，清除不可逆。**

1. 写入变更通路必经校验网关；禁止后台静默抽取记忆；网关两条互斥分支：识别命中矛盾入队列不落盘；漏检矛盾随链路落盘。

3. 识别命中的矛盾记忆不自动打失效标记，送入冲突队列等待外部复核；网关漏检矛盾直接落盘。
4. 六层存储：层间晋升‑降级、归档‑降级规则可同源偏置，层间流转强制携带 version_id；**支持按来源、version_id 定位；无开箱即用跨层事务级批量清除接口；记忆向量库与业务知识库物理隔离；多存储异步同步存在短暂视图不一致。**

6. 内核审计只采集流过内核模块事件；**旁路篡改操作不经过内核任何模块，审计模块无采集机会，内核审计无对应记录【范式本体感知边界，非审计模块功能缺失】。**
7. M0‑Composite 属于带风险抑制挡板的多存储自演化信息系统；**挡板仅抑制风险，不能根除机理缺陷；挡板失效会释放下层继承自 M1‑M5 的固有缺陷；同源自噬成立前提：错误记忆穿透挡板流入推理上下文。**

## 步骤 4：五类运行工况判定【v2.0｜引入同源自噬公理作为滑变驱动因子】

> 
> 工况属于运行时动态属性，非静态代码属性；**同源自噬成立的前提：错误记忆穿透挡板未被过滤、预审、标记隔离，并且实际流入 Agent 推理上下文；任一挡板 / 隔离机制生效，则抑制同源放大闭环，不能彻底根除；推动稳态 → 偏移态 → 冲突态逐级滑落；静默业务污染态是冲突态向崩溃态过渡子形态。**
> 故障诱因三分：范式本体机理缺陷 / 项目实现缺陷 / 载体 & 外部诱因。

1. **稳态【组合架构原生】**
Agent 工具调用行为正常；校验网关 LLM 漏检率低；挡板全部配置正确；双时间戳、COW 版本链正常；六层存储层间流转、归档‑降级规则中立；多存储异步同步短暂滞后在合理区间；冲突队列低水位；RRF 检索权重配置中立；渐进式披露加载记忆，Agent 推理输出符合业务预期。
2. **偏移态【组合架构原生】**
诱因：①Agent 幻觉生成错误记忆，显式调用写入工具，**校验网关 LLM 漏检，错误记忆穿透挡板落盘；②归档‑降级、层间晋升‑降级规则同源偏置，错误记忆跨层迁移扩散；③COW 被污染快照执行回滚回放，快照回放重新激活污染源写入存储；④RRF 检索权重同源偏置，检索结果系统性偏向同源记忆；⑤挡板配置错误，抑制机制失效；⑥多存储异步同步滞后放大。**
现象：Agent 引用错误记忆；单轮 / 多轮业务异常；内核不自愈；错误记忆持久化保存在六层多形态存储；若错误记忆未被隔离过滤，多次查询检索会反复召回，存在滑向冲突态风险；修复依赖上层二次复核、快照回放前置校验、检索 / 归档流转配置复核介入【外部自研增补】。

> 
> ⚠️M0‑Composite 特有偏移放大：校验网关属于抑制层，一旦漏检，错误记忆走完完整写入链路持久落地；同源偏置的层间 / 归档规则造成错误记忆跨存储形态扩散；污染快照回放会批量重新激活历史错误记忆。

3. **冲突态【组合架构原生】**
诱因：多条互相矛盾记忆条目被网关漏检同时持久存入六层存储；归档‑降级、层间流转同源偏置扩大污染范围；RRF 检索同时召回多条矛盾记忆送入推理上下文；COW 回放引入新旧矛盾快照。

> 
> 👉**静默业务污染态（业务子形态）：M0‑Composite 全部内核模块运行正常；工具请求、网关校验、版本生成、存储写入、检索全部流程无报错；记忆条目格式、元数据、证据链全部合法；但是记忆业务事实错误 / 互相矛盾；持续被检索召回送入 Agent 推理上下文；上层业务目标失效；内核进程本身没有 crash。**
> 同源自噬驱动路径：
> ‑主写入回流：Agent 幻觉显式写入 →网关漏检穿透挡板 →错误记忆落盘 →后续检索召回流入推理上下文。
> ‑层间流转回流：同源偏置归档‑降级、层间晋升‑降级配置，错误记忆跨六层存储迁移扩散。
> ‑快照回流：COW 污染快照执行回滚回放 →快照回放重新激活污染源写入六层存储 →检索召回送入推理。
> ‑挡板失效回流：挡板配置错误失效；下层继承缺陷向上暴露。
> ‑公共载体旁路回流：**旁路篡改操作不经过内核任何模块，审计模块无采集机会，内核审计无对应记录；篡改内容检索直接加载。**

4. **视图分裂态（视图不一致现象）【组合架构本体现象】**

> 
> 触发条件：
> 1）六层多存储组件异步同步延迟；不同存储层之间记忆条目短暂不一致（属于异步多存储固有延迟，非故障；业务持续查询会逐步收敛）。
> 2）COW 版本链切换不同历史快照；**COW 版本链切换属于预期版本演进语义，当前视图与历史快照不同属于正常行为；仅当版本切换过程中出现新旧版本记忆同时被召回，且业务误将二者当作同一时间基线，造成业务误判时，才构成视图一致性风险【外部依赖・业务层】，不属于范式本体视图分裂故障。**
> 补充精度：
> ‑外部进程旁路篡改某一份底层存储库；磁盘‑内核视图不一致为篡改带来可见后果；归【范式本体感知边界 + 载体层访问控制缺口】，不作为独立分裂态故障。
> ‑多存储短暂异步滞后属于架构预期异步行为，不等于故障。

5. **崩溃态【多重条件叠加】**
载体层 / 中心控制点故障触发：写入校验网关服务完全宕机；图数据库 / 向量库 / 对象冷归档大规模故障；网络链路整体断裂；**M0‑Composite 内核进程存活；记忆写入或者记忆查询业务链路整体失效；属于业务层面崩溃，非进程 crash。**

> 
> 说明：网关 LLM 漏检、归档层同源偏置、冲突记忆共存、快照污染回放、异步存储短暂视图滞后，不会直接造成崩溃态；网关被攻陷属于中心控制点单点失效场景归入崩溃态。

> 
> 工况诱因二分
> ‑范式本体机理缺陷：校验网关依赖 LLM 必然存在漏检；归档‑降级、层间晋升‑降级规则可同源偏置，带来跨层污染扩散；COW 快照链可被污染，快照回放重新激活污染源；RRF 检索权重配置可同源偏置；多存储异步同步带来短暂视图差异；挡板仅风险抑制不能根除下层继承缺陷；**支持按来源、version_id 定位，无开箱即用跨层事务级批量清除接口，清除不可逆；内核审计只记录流过内核模块事件；旁路篡改操作不经过内核任何模块，审计模块无采集机会【范式本体感知边界 + 载体层访问控制缺口】；满足同源自噬闭环条件（需要满足前置成立条件）。**
> ‑项目实现缺陷：挡板配置错误失效；RRF / 归档 / 层间流转配置未独立复核；冲突队列缺少运维监控；缺少快照回放前置校验；缺少底层存储篡改检测；生命周期治理缺失。
> ‑载体 & 外部诱因：Agent LLM 幻觉；校验网关 LLM 幻觉 / 服务不可用；图 / 向量 / 对象存储 IO 故障；网络抖动；网关自身被攻陷；外部进程绕过内核直接篡改底层持久化库。

‑冲突队列持续堆积，COW 快照、归档记忆持续累积带来存储膨胀；**支持按来源、version_id 定位记忆条目，无开箱即用跨层事务级批量清除接口。**
5. **死（破坏终止）【组合架构原生】**
‑多重载体条件叠加：写入校验网关服务彻底宕机（或网关被攻陷）；图数据库、向量库、冷归档对象存储大规模彻底故障；网络链路完全断裂；M0‑Composite 内核进程存活；记忆写入 / 记忆查询业务链路整体失效，进入崩溃态。

> 
> 仅网关漏检、矛盾记忆共存、快照污染回放、层间同源偏置、多存储短暂异步视图滞后，不会触发崩溃态。

## 步骤 6：架构优势、固有机理约束、条件触发隐患【v2.0 条件式风险书写规范】

### 架构优势【组合架构原生】

1. **顶层约束彻底关闭后台静默 LLM 抽取记忆；记忆写入必须来自 Agent 显式 tool‑call 或者人工标注，消除 M2/M3/M5 隐式抽取幻觉落盘的源头。**
2. 写入通路增设校验网关挡板；Agent 不能直接直写底层存储；记忆绑定原始证据链；**网关未被攻陷前提下双时间戳网关统一签发，上层不可伪造。**
3. COW 写时复制 diff 版本审计层：每次变更留存版本快照 diff，支持记忆版本回滚，修复 M5 原地改写无版本、rollout 不可撤回缺陷；快照回放仅激活已有污染，回放本身不制造错误。
4. 六层冷热分层存储；工作页‑召回缓存‑图谱‑向量‑冷归档‑版本审计；层间晋升‑降级流转，强制携带 version_id；**记忆向量库与业务知识库物理隔离，杜绝混库风险；萃取 M3 能力：Episode 一等公民、Fact 有效期标记；检索接口默认时间过滤过期事实；矛盾识别命中送入冲突队列等待复核，规避 LLM 自动判定失效误判；支持按来源、version_id 定位记忆条目。**
5. 混合多源 RRF 检索（向量 + BM25 + 图多跳遍历）；渐进式披露加载，高层摘要优先，完整 Episode/Fact 需要显式 recall 工具调用才加载，控制上下文 token 膨胀。
6. **内核原生全链路审计日志；完整记录流过内核模块的全部记忆操作事件。**

### 继承 M0‑Composite 组合架构通用固有机理约束

1. **挡板≠彻底根除缺陷：校验网关、隔离挡板属于风险抑制机制；挡板配置错误、LLM 漏检、挡板绕过，下层继承自 M1‑M5 的机理缺陷依然可以向上传导；网关放行仅格式 / 初筛通过，不等于业务事实正确；深度业务语义校验全部属于【外部自研增补】。**
2. 全部上层改良仅抬高稳态门槛，推迟偏移‑冲突‑静默业务污染态‑崩溃态到来；**不能根除范式底层固有机理取舍。**

### M0‑Composite 范式特有取舍与条件触发隐患

> 
> 风险统一条件式描述：当特定边界条件触发 / 内置缓解机制失效，则暴露对应风险。

1. **写入校验网关依赖 LLM，存在幻觉漏检；错误记忆可以穿透挡板完整走完写入链路持久落盘【范式本体机理缺陷】**：**当 Agent 产生格式合法的幻觉记忆，显式调用记忆写入工具；校验网关 LLM 发生漏检；错误记忆持久写入六层存储；校验网关输出二次复核属于【外部自研增补】。**
2. **归档‑降级、六层存储层间晋升‑降级规则配置可同源偏置，造成错误记忆跨层迁移扩散【范式本体机理缺陷】**：**当归档、层间流转规则被同源偏向配置；错误记忆被保留在高频层，正确记忆被误归档；或错误记忆跨层扩散至多存储形态；归档‑降级、层间流转规则独立复核属于【外部自研增补】。**
3. **COW 写时复制快照链可被错误记忆污染；执行版本回滚回放，快照回放会重新激活历史污染源【范式本体机理缺陷】；回放机制本身不创造错误；快照被污染源头：①网关漏检穿透挡板写入污染记忆（本体缺陷）；②旁路篡改底层存储引入污染【范式本体感知边界 + 载体层访问控制缺口】**：**当快照链中存在被污染历史版本；业务执行回滚回放操作；错误记忆被重新写入六层存储；快照回放前置校验属于【外部自研增补】。**
4. **RRF 混合检索权重、排序配置可同源侧传入，带来检索端同源偏置风险【范式本体机理缺陷】**：**当 RRF 融合权重配置被同源偏向设置；检索召回结果系统性偏向同源记忆；RRF 检索配置独立复核属于【外部自研增补】。**
5. **多存储组件异步同步，会出现短暂多存储视图不一致【范式本体机理缺陷】**：**多存储之间同步尚未完成，不同存储层记忆条目存在差异；业务持续查询随同步完成会逐步收敛；多存储同步监控告警属于【外部自研增补】。**
6. **识别命中的事实矛盾记忆不会内核自动消解 / 自动标记 invalid_at 失效；全部送入冲突事件队列，等待二次 LLM 复核或者人工复核【范式本体机理缺陷】**：**大量矛盾产生会造成冲突队列堆积；冲突队列运维监控、复核闭环属于【外部自研增补】。**
7. **网关为写入通路中心控制点；网关服务宕机则全部记忆写入通路中断【范式本体机理缺陷】**：**无内核原生写入通路降级策略；网关高可用容灾属于【外部自研增补】。网关自身被攻陷可篡改双时间戳，归入崩溃态。**
8. **支持按来源、version_id 定位记忆条目，无开箱即用跨层事务级批量清除接口；清除需要多存储分别执行，清除不可逆【范式本体机理缺陷】**：**错误记忆已经扩散到六层多存储形态，缺少内核原生跨层统一清除手段；跨层污染批量清除封装属于【外部自研增补】。**
9. **Agent 必须显式 tool‑call 调用才会持久化记忆；Agent 忘记调用写入工具，则记忆不会被持久保存【范式本体机理缺陷】**：**Agent 侧记忆调用行为监控提示属于【外部自研增补】。**
10. **COW 快照、冲突队列、归档记忆无内核原生自动清理；随运行时间推进存储持续膨胀【范式本体机理缺陷】**：**记忆生命周期治理、快照压缩清理、冲突队列归档属于【外部自研增补】。**
11. **挡板属于风险抑制；挡板配置错误 / 失效，继承自 M1‑M5 的底层子模块缺陷向上传导暴露【范式本体机理缺陷】**：**内核挡板配置变更独立复核属于【外部自研增补】。**
12. **旁路篡改操作不经过内核任何模块，审计模块无采集机会，故内核审计日志中无对应记录【范式本体感知边界 + 载体层访问控制缺口】**：**底层存储库哈希篡改检测属于【外部自研增补】。**
13. **文件载体型自演化闭环：网关漏检落盘、归档‑层间流转同源偏置、COW 快照污染回放、RRF 检索同源偏置、挡板失效、载体旁路篡改；错误记忆未被过滤预审流入推理上下文，持续放大漂移【范式本体机理缺陷】**：**若无上层业务过滤干预；多类风险叠加，推动工况从稳态滑向冲突态【外部自研增补】。**

## 步骤 7：重构备选方案与校验

标记：✅上层封装扩展（上层业务 / 管控面，不修改 M0‑Composite 内核源码） / ⚠️修改 M0‑Composite 内核源码 / ⚪概念方案｜大规模架构改动

1. **校验网关输出二次复核层【✅上层封装扩展】**
修复逻辑：校验网关放行的记忆载荷，向下写入时序‑版本管控之前，业务层执行独立二次事实 / 矛盾复核。
代价：额外 LLM 算力开销；复核自身存在幻觉漏检风险；**不能 100% 拦截全部幻觉记忆；无法防护绕过内核直改底层存储的篡改。**
2. **归档‑降级 & 层间流转规则独立复核层【✅上层封装扩展】**
修复逻辑：归档降级、六层存储层间晋升‑降级配置变更，业务层独立复核，拦截明显同源偏向配置。
代价：业务开发成本；**不能完全阻止合法配置间接产生的同源偏向。**
3. **COW 快照回放前置校验层【✅上层封装扩展】**
修复逻辑：执行版本快照回滚回放操作前；业务层对目标快照做事实风险预审；高污染风险快照阻断回放。
代价：算力开销；预审存在误判漏判；**仅防护回放动作；不能修复快照链内部已经存在的污染。**
4. **RRF 检索配置独立复核层【✅上层封装扩展】**
修复逻辑：RRF 融合权重、检索过滤模板发生配置变更，业务层独立复核，拦截明显同源偏向配置。
代价：业务开发；**不能完全阻止合法配置下间接产生的同源检索偏向。**
5. **多存储同步监控告警层【✅上层封装扩展】**
修复逻辑：业务层持续比对六层存储之间关键条目状态；检测异步同步长时间不收敛触发告警。
代价：业务侧轮询比对开销；**仅监控告警，不能加速异步同步过程。**
6. **冲突队列运维闭环封装层【✅上层封装扩展】**
修复逻辑：冲突队列水位监控告警；封装二次 LLM 批量复核、人工复核工作台接口；过期冲突条目归档。
代价：业务开发；需要业务定义冲突归档策略；归档之后不可恢复。
7. **网关高可用容灾封装层【✅上层封装扩展】**
修复逻辑：多实例部署写入校验网关；实现写入通路高可用容灾降级。
代价：运维资源开销；**属于业务部署层面，不改变内核单控制点机理。**
8. **跨层污染批量清除封装层【✅上层封装扩展】**
修复逻辑：业务层基于内核提供的来源、version_id 定位能力；封装跨多存储形态分步清除工作流；执行后做多存储状态一致性校验；清除前业务侧留存备份。
代价：业务开发；非内核事务级原子清除；分步清除存在中间状态；清除不可逆。
9. **底层存储篡改检测告警层【✅上层封装扩展】**
修复逻辑：业务层对图数据库、向量库、冷归档数据集维护校验哈希；定期比对；哈希不匹配判定底层被旁路篡改，触发告警。
代价：存储哈希元数据维护开销；**仅告警检测，不能阻止操作系统 / 数据库层面篡改，不能修复篡改后的内容【范式本体感知边界 + 载体层访问控制缺口】。**
10. **Agent 记忆调用行为监控提示层【✅上层封装扩展】**
修复逻辑：业务编排层监控 Agent 会话；检测长时间没有调用记忆写入 tool‑call；输出提示告警。
代价：业务开发；**仅做提示告警，无法强制 Agent 必须调用写入工具。**
11. **记忆生命周期治理封装层【✅上层封装扩展】**
修复逻辑：业务定时执行：COW 快照压缩归档、冲突队列归档、冷归档过期记忆清理。
代价：存储与业务开发开销；清理后版本 / 记忆不可恢复。
12. **挡板配置变更独立复核层【✅上层封装扩展】**
修复逻辑：校验网关、风险挡板规则发生配置修改，业务层独立复核；拦截高风险抑制关闭配置。
代价：业务开发；**不能防护运行时 LLM 本身幻觉漏检。**
13. **异源校验闸门（网关输出二次复核 + 快照回放前置校验 + 归档层流转配置复核 + 检索前置校验 + 存储篡改检测）【⚪概念方案｜大规模架构改动｜外部自研增补】**
修复逻辑：写入落盘前、快照回放前、归档层间流转执行前、检索输出送入推理前插入独立异源校验主体；**校验主体必须和 M0‑Composite 整套系统相异；禁止同源 Agent / 网关自校验同源记忆；传递压缩记忆摘要；偏移超标阻断写入 / 回放 / 送入上下文。**
代价：架构改动巨大；算力开销爆炸；存在大量误杀；**校验主体自身同源漂移风险（自噬校验自噬）；M0‑Composite 内核本体不内置。**

> 
> 共同铁律：全部优化仅抬高稳态门槛，推迟偏移‑冲突‑静默业务污染态‑崩溃态到来；**不能彻底根除 M0‑Composite 底层取舍：网关 LLM 必然漏检；归档‑层间流转同源偏置；COW 快照链可被污染回放；RRF 检索同源偏置；多存储异步视图不一致；网关写入单点；Agent 必须显式调用写记忆工具；无内核原生跨层事务级批量清除；挡板仅做风险抑制；底层存储存在旁路篡改缺口这些固有机理。**

> 
> 补充说明：大量标记【外部自研增补】属于组合架构设计取舍；M0‑Composite 内核聚焦：工具接入、校验网关挡板、时序‑版本管控、六层存储调度、混合检索、渐进披露、冲突队列、原生审计；**深度二次校验、归档‑层间流转复核、快照回放防护、运维监控、存储篡改检测、生命周期治理全部留给上层业务编排。**

## 步骤 8：闭环复审校验【v2.0】

1. 对齐 M0 素材萃取约束：萃取 M1‑M5 能力，增设隔离挡板封闭原有范式缺陷；完成**权限原子化协议完整六维扫描；新增完整逐模块同源自噬分析表；厘清网关识别命中矛盾 / 网关漏检矛盾两条互斥通路；修正双时间戳绝对化表述；修正 COW 版本切换视图分裂态定义；全文统一旁路篡改审计采集口径；补齐归档‑降级、层间晋升‑降级决策与同源偏置缺口；补齐跨层污染定位‑批量清除缺口；严格区分写入变更通路 / 查询读取通路；关闭后台静默抽取；识别全套新增特有风险；严格区分三类缺陷：范式本体机理缺陷 / 项目实现缺陷 / 载体外部诱因；同源自噬增加 M0‑Composite 特有前置成立条件。**
2. 六条动态契约逐条核验；补齐归档‑降级、层间流转同源偏置缺口；快照回放污染缺口；检索同源偏置；多存储异步视图；冲突队列不自动消解；审计仅采集流过内核事件缺口；缺口定位：格式契约≠业务事实一致性；**同源自噬需要错误记忆穿透挡板流入 LLM 推理上下文作为前提；挡板仅抑制风险，不根除缺陷。**
3. 五类运行工况；修正 COW 版本切换视图分裂态；区分多存储短暂异步视图属于架构预期；偏移态补充归档‑层间流转同源偏置带来的滑变；区分静默业务污染态子形态；崩溃态包含网关被攻陷单点失效场景。
4. 旺‑生‑休‑克‑死耦合映射自洽；休眠定义严格；识别全部负向自噬通路：网关漏检主写入回流、归档‑层间流转跨层扩散回流、COW 快照污染回放回流、挡板失效回流、载体旁路篡改回流。
5. 重构备选区分上层封装扩展 / 修改内核源码 / 概念方案；新增归档流转复核、跨层污染批量清除封装；异源校验闸门写明**自噬校验自噬风险**；不宣称补齐全部契约短板。
6. 落实铁律：** 挡板≠根除机理缺陷；网关放行 / 格式合法不等于业务事实正确；关闭后台静默抽取属于顶层硬性约束；多存储短暂异步同步视图差异属于架构预期行为；快照回放只激活已有污染源

### 留给行业的思辨问题（继承 M1‑M5 全部记忆思辨 + M0‑Composite 新增专项思辨）

1. 记忆写入完全禁用后台静默抽取，强制依赖 Agent 显式`tool‑call`；在 “漏写记忆风险” 与 “静默 LLM 抽取幻觉风险” 之间如何权衡；该约束应当内核强制固化，还是开放为业务可开关配置？
2. 写入校验网关作为第一层风险抑制挡板；网关 LLM 漏检属于不可彻底消除的固有现象；二次事实复核属于内核职责，还是上层业务管控面责任？
3. COW 写时复制快照链机制；快照回放只会激活历史已存在污染，本身不生成错误；快照回放前置风险校验应当内核内置，还是交由上层业务实现？
4. 六层存储存在层间晋升‑降级、归档‑降级流转；同源偏置可造成错误记忆长期驻留高频层、正确记忆被误归档；层间流转 / 归档策略的正确性校验，应当归内核还是上层业务？
5. 网关识别命中的矛盾记忆送入冲突队列，内核禁止自动消解矛盾；矛盾自动 LLM 消解是否应当开放可配置开关，还是强制全部走人工 / 二次复核队列？
6. 写入校验网关是写入通路唯一中心控制点，存在单点失效风险；写入通路降级旁路，是内核层面提供，还是完全交给上层多实例高可用部署解决？
7. 内核审计只采集流过内核模块的事件；底层存储被外部旁路篡改不会产生审计记录；底层存储防篡改检测属于内核职责还是上层防护？
8. 【v2.0 新增‑挡板设计视角】整套组合架构依靠多层挡板抑制继承自 M1‑M5 的固有缺陷，但挡板配置本身可以出错；挡板配置变更的正确性校验应当内核内置，还是上层配置复核？
9. 【v2.0 新增‑多层存储视角】六层冷热分层，多存储异步同步会带来短暂视图不一致；短暂异步视图差异应当被业务视为故障，还是作为系统固有行为接纳？
10.【v2.0 新增‑污染处置视角】内核可以按`version_id`、来源标签定位污染记忆，但**无开箱即用跨层事务级批量清除接口**；跨存储形态的污染批量清除，应当内核原生实现，还是上层业务封装分步清除工作流？

## 步骤 9 Agent 业务 / 管控面扩展模块‑精简版

> 
> ⚠️重要前置标注：**以下模块不属于 M0‑Composite 组合架构内核本体；全部运行在上层业务编排；本处仅输出：模块名称｜核心缺陷（机理）｜可观测表征｜重构思路；不执行完整八步拆解。**

图6｜冲突复核回写子通路

sequenceDiagram
    participant Agent
    participant Tool as Agent工具请求接入
    participant Gate as 写入校验网关
    participant Queue as 冲突事件队列
    participant Reviewer as 上层复核业务(外部增补)
    participant Ver as 时序-版本管控
    participant Sched as 六层存储调度
    participant Store as 六层底层存储
    participant Audit as 全链路审计

    Agent->>Tool: write_memory
    Tool->>Gate: 标准化写入载荷
    Gate->>Gate: LLM 一致性&矛盾初筛 识别命中矛盾
    Gate->>Queue: 送入矛盾载荷+证据元信息 生成 conflict_task_id
    Gate-->>Tool: status=enter_conflict_queue
    Tool-->>Agent: 返回结果 不写六层业务存储
    Note over Audit: 采集矛盾入队事件

    Reviewer->>Queue: conflict_queue_get_task
    Queue-->>Reviewer: 待复核任务载荷+证据链
    Reviewer->>Queue: conflict_queue_review_resolve

    alt write_pass
        Queue->>Ver: 放行原始载荷重新下发
        Ver->>Ver: 签发双时间戳 生成 COW-diff 新 version_id
        Ver->>Sched: 带完整元数据记忆条目
        Sched->>Store: 分发写入六层存储
        Store-->>Sched: IO 结果
        Sched-->>Ver: 存储结果
        Ver-->>Queue: 回写 version_id
        Note over Audit: 采集复核放行+版本生成+存储写入事件
    else mark_invalid
        Queue->>Queue: 标记完结 生成失效元记录 不入业务六层
        Note over Audit: 采集标记失效事件
    else discard
        Queue->>Queue: 标记完结 载荷归档 不入业务六层
        Note over Audit: 采集丢弃事件
    end

    Queue-->>Reviewer: 决议执行结果

备注：网关识别命中的矛盾入冲突队列不落盘；复核决议有 write_pass（放行重新走完整写入）/ mark_invalid（标失效）/ discard（丢弃）三种。网关漏检的矛盾不会进入该队列，直接随正常链路落盘。 复核逻辑由外部实现，内核只执行决议分发。冲突队列持续堆积不会自动消解，运维闭环属外部自研增补。

备注：工况是运行时动态属性。稳态→偏移态→冲突态→静默业务污染态→崩溃态逐级滑落，同源自噬是滑变驱动因子。 视图分裂态是分支：多存储异步同步短暂不一致属架构预期行为，不是故障；COW 版本切换属预期演进语义，仅当业务误把新旧当同一时间基线才构成风险。静默业务污染态是最高风险子形态：进程全部正常、格式合法，但业务事实错误。崩溃态是业务层面崩溃（内核进程存活），由多重载体条件叠加触发。
